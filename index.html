Pick-Up-Anywhere MUD

PUAMUD

PUAMUD (Pick-Up-Anywhere Multi-User Dungeon) is a new type of MUD game being developed for discord and discord-like platforms with an emphasis on character building and social interaction.

See Platforms Read Devlog

Active

Discord

PUAMUD is being developed to be played entirely within Discord. Players can interact with the game through text commands, slash commands, and Discord's interactive interfaces.

Latest Devlog
